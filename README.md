Small Office Network Design Using Cisco Packet Tracer

Project Overview

Designed and simulated a small office network using Cisco Packet Tracer, connecting Engineering and Sales departments with a shared office server.

The network uses VLAN segmentation and Router-on-a-Stick inter-VLAN routing to provide organized communication between departments.

Network Architecture

Engineering Department – VLAN 10

Sales Department – VLAN 20

Office Server – VLAN 30

Cisco 2960 Layer 2 Switch

Cisco 2911 Router

IEEE 802.1Q Trunking

IPv4 Addressing

Technologies Used

Cisco Packet Tracer

Cisco IOS CLI

VLAN Configuration

Inter-VLAN Routing

IPv4 Networking

ICMP / Ping Testing

Key Implementations

Created separate VLANs for Engineering, Sales and the shared server.

Configured switch access ports.

Configured an 802.1Q trunk connection.

Implemented Router-on-a-Stick routing.

Assigned IP addresses and default gateways.

Performed connectivity testing using ping commands.
